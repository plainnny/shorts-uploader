Privacy Policy

Effective date: October 5, 2026

This policy explains how Shorts Auto Uploader (the "Tool") handles data. The Tool is a private script used only by its owner to upload the owner's own videos to the owner's own channel.

1. YouTube API Services

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

2. Information the Tool accesses

  • OAuth tokens. When the owner signs in, Google issues an access token and a refresh token for the single scope https://www.googleapis.com/auth/youtube.upload.
  • Video files and metadata (title, description, tags, category, privacy setting) that the owner chooses to upload.
  • The upload response from YouTube (video ID and privacy status), shown on screen to confirm the upload.

The Tool does not access any other YouTube or Google Account data, such as channel analytics, subscribers, comments, watch history, email or contacts.

3. How the information is used

The information is used only to upload the owner's videos to the owner's channel when the owner runs the Tool.

4. Storage

  • The refresh token is stored in a local file (token.json) on the owner's own computer.
  • Access tokens are kept in memory only while the Tool is running.
  • No data is stored on any server operated by the Tool. The Tool has no server, database, cookies or analytics.

5. Sharing

The Tool sends data only to Google (YouTube Data API and Google OAuth endpoints) to perform the upload. It does not share, sell or disclose any data to any other party.

6. Revoking access and deleting data

  • Access can be revoked at any time on the Google security settings page (Third-party apps & services).
  • Deleting the local token.json file removes all stored authorization data from the owner's computer.
  • Uploaded videos can be managed or deleted in YouTube Studio.

7. Children

The Tool is not directed to children and is used only by its adult owner.

8. Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
