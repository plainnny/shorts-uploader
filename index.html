Shorts Auto Uploader

A private, single-user tool. Not a public service.

What it is

Shorts Auto Uploader is a small personal script that runs on its owner's Windows PC. It uploads short vertical videos, created by the owner, to the owner's own channel using the YouTube Data API v3 (videos.insert).

Who uses it

Only the channel owner. There are no other users, no sign-up, and no public access. The script is not distributed or offered to anyone else.

How it works

  • The owner signs in once with their Google Account through Google's standard OAuth 2.0 consent screen (desktop-app flow).
  • The only permission requested is https://www.googleapis.com/auth/youtube.upload.
  • The resulting refresh token is stored only on the owner's PC.
  • For each video, the owner reviews the title, description and privacy setting before the upload is run.
  • Expected volume: a few uploads per day at most.

What it does not do

  • It does not read, collect, store or analyze data from other channels or users.
  • It does not use search, comments, analytics or any other YouTube API endpoint.
  • It does not send any data to servers other than Google's.
